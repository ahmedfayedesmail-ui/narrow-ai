# Contributor Covenant Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community.

Examples of unacceptable behavior include harassment, insults, intimidation, discrimination, personal attacks, and publishing private information without consent.

Project maintainers are responsible for clarifying and enforcing these standards. They may remove, edit, or reject contributions that violate this Code of Conduct and may temporarily or permanently exclude contributors for unacceptable behavior.

Report conduct concerns privately to the repository owner through GitHub. Be respectful, specific, and include relevant context.
